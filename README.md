# Sound Decibel Meter

Measure ambient sound levels with the **Sound Decibel Meter**, a free online tool built with HTML, CSS, JavaScript, and Bootstrap 5. Monitor microphone input in real time, view sound levels, and compare readings with common everyday noise levels.

## ✨ Features

- **Real-Time Sound Monitoring** – Visualize microphone input as you make sounds.
- **Decibel Display** – View an estimated sound level in dB.
- **Live Sound Meter** – Monitor changes in sound intensity.
- **Common Sound Level Reference** – Compare readings with everyday sounds.
- **Save Results** – Record measurement results for later reference.
- **Download Results** – Export results in supported formats.
- **Download as PNG** – Save a screenshot of your results.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.
- **Privacy-Friendly** – Microphone access requires your permission.

## 📖 How to Use

1. Open the Sound Decibel Meter tool.
2. Click the button to start measuring.
3. Allow access to your microphone.
4. Watch the sound level meter respond to nearby sounds.
5. Compare the displayed reading with the common sound level reference.
6. Save, download, or share the results if these features are available.


## ⚠️ Accuracy Disclaimer

This tool analyzes microphone input to estimate sound intensity. Unless the microphone and software are properly calibrated, the displayed dB values may not represent accurate physical sound pressure levels (dB SPL). Results can vary depending on microphone sensitivity, operating-system processing, automatic gain control, and environmental conditions.

Do not use this tool as a certified instrument for occupational noise compliance or other safety-critical measurements.

## 🔒 Privacy

The tool requests microphone access only when needed. Review the implementation to confirm how audio is processed and whether any data is transmitted or stored before using it with sensitive audio.

## 🌐 Browser Compatibility

Use a modern browser that supports the Web Audio API and microphone access, such as Google Chrome, Microsoft Edge, Firefox, or Safari.
